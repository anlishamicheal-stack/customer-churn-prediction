📊 Customer Churn Prediction Dashboard
Overview
This project predicts customer churn for a telecom company using Machine Learning (XGBoost) and provides an interactive Streamlit dashboard for visualization and explainability.
The goal is to help businesses identify customers at risk of leaving and take proactive retention measures.
📊 Example Output
Prediction: “Churn” or “No Churn” for selected customers.
SHAP Summary Plot: Shows top features driving churn.
Force Plot: Explains individual customer predictions.
